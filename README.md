## About

**YokaiVerse** is an open-source platform that brings **Anime, Manga, and Webtoons** together in a single, unified experience.

Built with a **Privacy First** philosophy, YokaiVerse minimizes data collection and gives users full control over their experience. The project is designed to be lightweight, customizable, and completely transparent.

## How to Host

### 🇬🇧 English

1. Clone the repository.

   ```bash
   git clone https://github.com/Yushtify/YokaiVerse.git
   cd YokaiVerse
   ```

2. Install dependencies.

   ```bash
   npm install
   ```

3. Start the development server.

   ```bash
   npm run dev
   ```

4. Build for production.

   ```bash
   npm run build
   ```

5. Deploy the generated files to your preferred hosting provider.

### 🇹🇷 Türkçe

1. Depoyu klonlayın.

   ```bash
   git clone https://github.com/Yushtify/YokaiVerse.git
   cd YokaiVerse
   ```

2. Bağımlılıkları yükleyin.

   ```bash
   npm install
   ```

3. Geliştirme sunucusunu başlatın.

   ```bash
   npm run dev
   ```

4. Production sürümünü oluşturun.

   ```bash
   npm run build
   ```

5. Oluşan dosyaları tercih ettiğiniz hosting sağlayıcısına yükleyin.
